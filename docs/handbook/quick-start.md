# Your first three notes

Allow ten minutes. Use a separate folder and invented information. You will create three notes, connect them and find them again.

## 1. Create the plan

Open LCOS Notes and choose the practice folder. Press **Ctrl+N**, enter `Garden plan` and choose Create. Type:

```markdown
# Garden plan

Goal: make a small herb garden.
- [ ] Choose a sunny spot
- [ ] List supplies
```

Press **Ctrl+S**. The title's asterisk disappears when saved.

## 2. Connect an idea

Press **Ctrl+N**, create `Herbs`, and enter:

```markdown
# Herbs

Basil and mint are candidates for [[Garden plan]].
```

Save. Place the caret in the link and press **Alt+Enter**. The plan opens. Backlinks shows that Herbs refers to it; activate that row to return.

## 3. Add a second connection

Press **Ctrl+N**, create `Supplies`, and write `Pots and compost for [[Garden plan]].` Save. Press **Ctrl+O**, select `Garden plan` and press Enter to reopen it. Add `See [[Herbs]] and [[Supplies]].` Save again.

## 4. Read and act

Press **Ctrl+E** to read the formatted plan. Click an unchecked task box to mark it done; the task change saves the buffer. Click a link to open its note. Press **Ctrl+E** again to edit source. Markdown marks remain visible while editing.

## 5. Find the notes again

Press **Ctrl+O**, type part of `Garden plan`, select the result and press Enter. Press **Ctrl+Shift+F**, search for `compost` and open the result. You have found notes by name and content.

The files now live in your chosen folder. Keep a separate backup if they become valuable. Following a missing link can create a note, so check its spelling. Continue with [writing](writing.md), [links](links.md) or [finding](finding.md).
