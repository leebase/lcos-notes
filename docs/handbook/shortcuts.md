# Keyboard shortcuts

These shortcuts apply to LCOS Notes 1.1.0. Menus also show the main actions.

| Keys | Action |
|---|---|
| Ctrl+N | New Note |
| Ctrl+O | Quick Switcher |
| Ctrl+S | Save in editor |
| Ctrl+E | Toggle Reading view |
| Ctrl+Shift+R | Reload from Disk, discarding unsaved edits without confirmation |
| F2 | Rename open note or selected tree item/tag |
| F6 | Move open note to a destination folder |
| Alt+Enter / Ctrl+click | Follow link in editor |
| Ctrl+Shift+F | Search note contents |
| Ctrl+Shift+B | Focus Backlinks |
| Ctrl+Shift+M | Focus Unlinked mentions |
| Ctrl+Shift+E | Show Notes tree |
| Ctrl+Shift+T | Show Tags |
| Ctrl+Shift+O | Show Outline |
| Ctrl+D | Open today's daily note |
| Alt+Left / Alt+Right | Previous / next existing daily note |
| Ctrl+Shift+I | Insert template in editor |
| Ctrl+Shift+H | Wrap or unwrap selection as highlight |
| Ctrl+Shift+Y | List current note's highlights |
| Enter | Activate selected result, tree row or Reading link |
| Space | Toggle a focused task in Reading view |
| Shift+click | Select text in Reading view |
| Escape | Cancel or close a dialog |

In Search, **Alt+R** toggles regex and **Alt+W** whole word. In New Note, **Alt+T** focuses the template choice and **Alt+N** fills Timestamp Name. In the capture window, **Alt+T** chooses today, **Alt+I** chooses Inbox, and **Ctrl+Enter** submits. Arrows navigate switcher and tree rows. See [Finding](finding.md), [Capture](capture.md), and [Troubleshooting](troubleshooting.md) before using reload on a dirty note.

In version 1.1.0, use the File menu for Open Vault…, New Vault… and
Recent Vaults…. [Upgrade](installation.md#upgrade-from-an-earlier-version) if these items are missing.
Ctrl+O selects notes within the current vault. See [Work with vaults](vaults.md).
