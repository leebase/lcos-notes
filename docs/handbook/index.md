# LCOS Notes handbook

LCOS Notes 1.0 is an offline Markdown notebook for LCOS and other X11 desktops. Your vault is a folder of ordinary files; notes are UTF-8 `.md` files. Start with a separate practice folder and invented examples.

- [Install and open](installation.md) takes you from the package to a vault.
- [Your first three notes](quick-start.md) is a ten-minute exercise.
- [Write and format](writing.md) and [Connect notes](links.md) explain the building blocks.
- [Capture an idea](capture.md) gives you an everyday routine.
- [Keyboard shortcuts](shortcuts.md) and the [complete reference](full-reference.md) provide detail.

Capture a thought before it disappears, give it a useful home later, and connect it to the notes you will use next. Arrange independent backups before relying on a vault. See [Coming from Obsidian](obsidian-users.md) for compatibility and [Troubleshooting](troubleshooting.md) for recovery.
